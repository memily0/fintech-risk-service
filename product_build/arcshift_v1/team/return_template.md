# Возврат Работы

- Участник / task IDs:
- Ветка / base commit / итоговый commit:
- Что реализовано и что только спроектировано:
- Изменённые модули и shared contracts:
- Новые зависимости и причина:
- Запуск из чистого checkout:
- Выполненные tests, точные команды и фактический результат:
- Не выполненные tests и причины:
- Данные: synthetic или реальные; snapshot/source/definition/availability IDs:
- Права: decision IDs для каждого purpose; что остаётся pending:
- Модель: task/horizon/features/splits и artifact/version либо no fit:
- Таблицы/метрики/ошибки/limitations; failed runs тоже перечислить:
- Screenshots/E2E/restore/rollback evidence где применимо:
- Security/privacy: auth isolation secrets logs exports:
- Обратная совместимость и migrations/rollback:
- Незакрытые проблемы и release blockers:
- Что нужно от другого направления:
- Reviewer и итерация проверки:

Raw данные, личные материалы, permission letters и restricted artifacts
в public PR не прикреплять. Безопасный summary/ID и отдельный разрешённый канал.
