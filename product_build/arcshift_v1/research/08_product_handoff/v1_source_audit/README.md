# Аудит Источников ArcShift V1

Дата: 05.11.2026. Фокус: Россия, внешние факторы как контекст.
Казахстан отдельно не включён. Это документальный и локальный аудит,
а не подключённые production feeds и не юридическое заключение.

## Этап И Результат

Выполнен первый подшаг V1-01: инвентаризация существующих рядов,
проверка официальной документации и условий использования. Спецификация
V1-00 подготовлена, но полное согласование G01/G02 ещё не завершено;
подготовка data contract не объявляет их закрытыми.

- [series_catalog.csv](series_catalog.csv): все 13 исходных и 6 производных колонок.
- [rights_matrix.csv](rights_matrix.csv): 9 семейств источников с отдельными
  статусами display, model use, CSV/JSON export и API redistribution.
- [source_evidence.csv](source_evidence.csv): адреса первичных документов,
  способ проверки и ограничения полученного evidence.
- [findings.csv](findings.csv): конкретные gaps и условия устранения.
- [local_snapshot_inventory.csv](local_snapshot_inventory.csv): статистика
  только уже существующего CSV, не новые данные провайдеров.
- [audit_status.json](audit_status.json): незакрытые решения и отсутствие
  автоматического допуска. [verification.md](verification.md): выполненные проверки.

Исходные research data, модели и код продукта не изменены. Batch builder,
connectivity checks и training не запускались. Просматривались информационные
страницы, включая метаданные и опубликованные на них примеры/таблицы;
API history, CSV/XLS bulk data не скачивались для нового датасета.

## 1. Российское Ядро

### Официальные Курсы Валют

Текущий код использует XML Банка России: R01235 для USD и R01239 для EUR.
Это официальные курсы в RUB за единицу валюты после нормализации номинала,
не intraday FX quotes. [XML документация](https://www.cbr.ru/development/sxml/)
и [описание DailyInfo](https://www.cbr.ru/development/dws/) подтверждают
способы получения, nominal/unit rate и различие датированных полей.

Нужно хранить effective date и факт/время получения отдельно от publication
time. Неизвестная историческая дата публикации остаётся unknown.
Проверка обновления по расписанию не превращает официальный курс в минутный.

### Ключевая Ставка

У ЦБ есть отдельный метод KeyRate и
[история с 17.09.2013](https://www.cbr.ru/hd_base/KeyRate/).
В существующем builder при отсутствии key rate берётся refinancing rate,
а признак происхождения теряется при standardize_series. Следовательно,
название key_rate не полностью описывает исторический ряд.

Для V1 предлагаем отдельные series IDs для key rate и refinancing rate,
без молчаливой склейки. Если потребуется длинная policy-rate history,
она должна иметь собственное определение и break marker. Не выбираем
вариант по выгодному AUC. Announcement time и effective date различаются;
новая ставка не должна появляться в as-of inputs раньше доступности.

### Кривая ОФЗ

Текущий pipeline берёт не цены четырёх конкретных облигаций, а точки
[бескупонной кривой](https://www.cbr.ru/hd_base/zcyc_params/)
на 1/2/5/10 лет, в процентах годовых. История на странице начинается
04.01.2003; эта заявленная граница не заменяет проверку полноты рядов.
Локальные MOEX CSV служат overlap comparison, а не основным текущим источником.

Парсер выбирает колонки по номерам 4/5/7/9. До ingest нужны проверки
заголовков maturities, units, пропусков и changes в структуре. Ссылка
на Мосбиржу на странице ЦБ требует отдельно проверить происхождение
и применимые права; зеркальное размещение не принимаем за новый license grant.

### Инфляция

Нужная задача: CPI по всей России, все товары и услуги, месяц к тому же
месяцу прошлого года; inflation = индекс в процентах минус 100.
Нельзя подменить его MoM, YTD, weekly CPI или региональной инфляцией.
Официальная [страница цен](https://www.rosstat.gov.ru/statistics/price/)
и [FAQ Росстата](https://www.rosstat.gov.ru/folder/165737)
помогают определить семейство; точный набор измерений и downloadable
resource для V1 пока не закреплены.

В коде используется зеркало NSEDC rsdocs_1031000110063: берётся второй
monthly record на дату, если их ровно два. Это не доказательство YoY
измерения. Правильный контракт должен выбирать размерности по метаданным,
а неоднозначность отклонять независимо от порядка строк.

Далее дата принудительно переносится на первый день следующего месяца.
Это assumption, не проверенная дата публикации. У Росстата есть
[датированные публикации](https://www.rosstat.gov.ru/storage/mediabank/157_09-10-2026.html)
и [план публикаций](https://www.rosstat.gov.ru/compendium/document/50798).
Нужны фактические release timestamps для prospective истории; для прошлых
периодов без подтверждения использовать явно обозначенный assumed lag.
Нельзя заявить historical point-in-time reconstruction по последнему файлу.

## 2. Международные Факторы

| Колонка | Текущий смысл | Решение этого аудита |
| --- | --- | --- |
| gold | Yahoo GC=F, дневной Close непрерывного futures-представления | Нужны contract/roll definition и источник с нужными правами; не подменять spot gold |
| brent | EIA Europe Brent Spot FOB, USD/barrel | Сохранять spot definition; проверить права именно на перепубликуемый ряд и задержку публикации |
| vix | Yahoo ^VIX, индекс, дневной Close | Cboe имеет исторические close; доступность файла не равна разрешению публичной выдачи/model use |
| sp500 | Yahoo ^GSPC, price index Close | Нужны права владельца/поставщика; FRED SP500 не является обходным бесплатным production feed |

[yfinance README](https://github.com/ranaroussi/yfinance) направляет к условиям
Yahoo и отделяет библиотеку от прав на данные. Поэтому не допускаем
существующий download как безусловную основу публичного сервиса.

Для VIX есть [официальная история Cboe](https://www.cboe.com/tradable-products/vix/vix-historical-data).
[FRED VIXCLS](https://fred.stlouisfed.org/series/VIXCLS) содержит copyright
Cboe; [FRED SP500](https://fred.stlouisfed.org/series/SP500) указывает
ограничения воспроизведения и 10-летнюю глубину доступной daily history.
[FRED terms](https://fred.stlouisfed.org/legal/) прямо сохраняют права
сторонних владельцев. Вывод аудита: эти страницы полезны для проверки
метаданных, но не доказывают права ArcShift на production использование.

Для gold дополнительно существует
[CME описание обновлений лицензионного соглашения](https://www.cmegroup.com/market-data/files/market-data-license-agreement-updates-june-2026.pdf).
Это evidence отдельного лицензионного режима для market/derived data,
а не выбранный договор, тариф или подтверждение эквивалентности GC=F.

## 3. Права И Бюджет

Ниже статусы допуска команды, не утверждение, что использование запрещено
во всех обстоятельствах. Hold означает, что оснований для нашего конкретного
публичного сценария пока недостаточно. Показ, обучение/расчёт производных,
выгрузка и API проверяются раздельно. Регистрация пользователя не устраняет
необходимость таких проверок; отсутствие оплаты в сервисе само по себе
не делает использование personal/research.

- **ЦБ:** [о сайте](https://www.cbr.ru/About/?PrtId=use) допускает воспроизведение
  со ссылкой, но содержит отдельную формулировку о коммерческих целях.
  [Соглашение](https://www.cbr.ru/user_agreement/) не даёт нам основания
  объявить эту неоднозначность снятой. Нужна фиксация допустимого конкретного
  сценария или письменное уточнение до коммерческого использования.
- **Росстат:** [условия открытых данных](https://rosstat.gov.ru/opendata)
  предусматривают бесплатное повторное использование, включая коммерческое,
  с условиями атрибуции и корректности. На этом шаге текст доступен в поисковом
  индексе официальной страницы; прямое открытие страницы и PDF завершилось
  timeout. Допуск условный: связать именно выбранный CPI resource с этими
  условиями и сохранить проверяемую редакцию, а не лицензировать всё зеркало.
- **Мосбиржа:** [ISS](https://www.moex.com/a2920) описывает технический доступ;
  [tariffs](https://www.moex.com/s1147) и
  [market-data policy](https://www.moex.com/en/datapolicy/) отдельно рассматривают
  dissemination, non-display и derived data. Ни delayed, ни EOD режим сами
  по себе не подтверждают бесплатный публичный display или модельный вывод.
- **EIA:** [reuse policy](https://www.eia.gov/about/copyrights_reuse.php)
  разрешает широкое использование собственных материалов с атрибуцией,
  но выделяет защищённые сторонние материалы. В
  [методологическом документе EIA, редакция 2020](https://www.eia.gov/analysis/handbook/pdf/STEO_Crude_Oil_Price.pdf)
  сказано о приобретении Brent/WTI history у Refinitiv и перепубликации
  с разрешения. Это причина проверить конкретную серию, не заключение,
  что её использование запрещено или обязательно платно.

Платные feeds не утверждены. Сначала уточняем подходящие условия бесплатных
вариантов; при недостатке прав фиксируем варианты: permission, другой источник
эквивалентного ряда либо отдельное изменение feature/target definition
с повторной оценкой. Не делаем вывод, что весь V1 невозможен без подписок.
В этом шаге ни один ряд не получил окончательный production admission.

## 4. Производные Не Являются Независимыми Источниками

Все шесть производных наследуют lineage, доступность и ограничения родителей.
Преобразование индекса в волатильность не является автоматическим обходом
прав исходных данных. Для каждой записи нужны formula version и input snapshots.

Текущий builder расширяет данные до календарных дней и forward-fills рынок
до 14 дней. Поэтому rolling(30) и rolling(252) считают строки календарного
grid, а не 30/252 торговые сессии. Это влияет на volatilites и z-score.
Forward-fill не создаёт новое наблюдение и не должен обнулять его возраст.

USD volatility здесь отражает изменения официального курса, не внутридневную
волатильность FX рынка; std не annualized. Drawdown считается от cumulative
maximum с начала доступной истории. Real key rate = nominal rate - trailing
CPI YoY, описательный ex-post proxy, не ex-ante реальная ставка.
Эти определения не объявляются ошибочными сами по себе: их нужно явно
зафиксировать или менять отдельной версией с проверкой последствий.

Даты US close нельзя автоматически считать известными на московское утро
того же дня. В старом yfinance loader timezone снимается; новый контракт
должен сохранять session close, timezone и information_as_of.

## 5. Следующий Подшаг

V1-01.1 закончен как документальный аудит. G03 остаётся pending.
В V1-01.2 уже подготовлены [candidate contract и offline checks](../v1_data_contract/README.md).
Exact CPI resource/provider codes и usage admission ещё открыты. Для завершения:

1. Сначала закрепить CPI YoY dimensions/resource, key-rate split и календарь
   доступности. Проверить, какие официальные источники подходят нашему scope.
2. Подготовить точные вопросы по display/model use/export/API для ЦБ,
   MOEX/curve и недопущенных глобальных рядов. Письма не отправляются автоматически.
3. Выбрать определения и permitted usage profile без молчаливого удаления
   компонентов существующего stress target. Если меняем target, согласовать
   новую задачу до model validation.
4. Зафиксировать конечный список test requests и лимиты для разрешённой
   технической проверки. До этого не запускать старый full-history builder.

После допуска конкретных источников возможны adapters и live pipeline.
Training, новые research experiments, публичный запуск, покупки и Git upload
не являются продолжением аудита по умолчанию. Общая последовательность
и текущая позиция: [stage_tracker.md](../v1_stage_tracker.md).
