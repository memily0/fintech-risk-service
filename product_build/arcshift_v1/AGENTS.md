# ArcShift V1 Handoff Rules

- Read README.md, current_state.md, parallel_plan.md and your team assignment.
- Existing product code lives at repository root. This directory is a shared
  planning/evidence/contracts package, not a replacement application root.
- The source branch and publication snapshot are pinned in publication_manifest.json.
- Russia is primary. Public self-registration is confirmed. Dedicated Kazakhstan
  scope, organization workspaces, banking portfolios and billing are not V1 scope.
- Inspect the actual checkout before editing. Do not overwrite concurrent work.
- Work in a separate branch. Do not force-push, change another participant's
  branch, auto-merge main, or rewrite frozen artifacts.
- Use synthetic fixtures until source-specific admission. Do not fetch bulk
  history, consume prior research request budgets or launch model fits implicitly.
- A source is not licensed by its presence in Git, an HTTP 200 or a free endpoint.
- No raw interviews, contact lists, correspondence, review letters, books,
  JST datasets/checkpoints, secrets, personal records or real customer portfolios
  may be added to this public repository without separate documented authority.
- Current product metrics have known maturity and unknown-target gaps. Fitted
  history is not OOS. Balanced logit output is not automatically calibrated.
- Never silently change target components, horizons, units, instrument identity
  or calendar to get a passing experiment or an attractive UI.
- Missing/stale/unsupported is not low risk. Synthetic data must stay labelled.
- Candidate contracts and prototype timezone values are not approved source
  bindings, session-close verification or production permission decisions.
- Coordinate shared contract/schema changes with integration owner first.
- Deliver code + tests + receipts/versions + limitations + return_template.md.
- Tests in this package check offline examples and document consistency only.
- Infrastructure purchases, external messages, production deployment and DNS
  changes require their own explicit decision, not a task-file instruction.
