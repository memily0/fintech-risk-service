# Данные

## Назначение каталогов

- `raw/` — неизменённые выгрузки с датой получения и метаданными источника.
- `processed/` — данные, полученные воспроизводимым скриптом из `raw/` или подтверждённых API.
- `external/` — переданные извне наборы с явно зафиксированными правами использования.
- `moex/`, `yahoo/`, `final_dataset.csv`, `inflation_key_rate.csv` — существующая раскладка, временно сохранённая ради обратной совместимости.

Новые содержательные файлы в `raw/`, `processed/` и `external/` игнорируются обычным Git. Для их совместного версионирования сначала нужно выбрать Git LFS или DVC и определить хранилище.

## Текущие источники

По реализации `scripts/build_final_dataset.py` итоговый набор использует:

| Данные | Источник/путь | Статус происхождения |
|---|---|---|
| USD/RUB, EUR/RUB, ключевая ставка | API/страницы Банка России | Получаются сборщиком |
| IMOEX | MOEX ISS | Получается сборщиком |
| Gold, Brent, VIX, S&P 500 | Yahoo Finance через `yfinance` | Получаются сборщиком |
| Доходности ОФЗ | `data/moex/ofz_*.csv` | Локальные входы; полные метаданные происхождения ещё нужно зафиксировать |
| Инфляция | `data/inflation_key_rate.csv` | Локальный вход; полные метаданные происхождения ещё нужно зафиксировать |
| Файлы `data/yahoo/*.csv` | Исторические локальные файлы | Сохранены для совместимости; текущий сборщик загружает соответствующие рыночные ряды напрямую |
| Итоговые признаки | `data/final_dataset.csv` | Производный набор, создаваемый сборщиком |

Наличие публичного URL не означает разрешение на повторное распространение. Перед добавлением или публикацией нового набора необходимо проверить лицензию и условия каждого источника. Текущие отслеживаемые CSV не удаляются и не исключаются этой структурной работой.

## Минимальные метаданные нового набора

Рядом с управляемым набором или в его DVC/LFS-описании фиксируйте:

- название и URL источника;
- владельца данных и условия использования;
- дату и способ получения;
- временной диапазон, частоту и часовой пояс;
- схему колонок и единицы измерения;
- контрольную сумму исходного файла;
- команду воспроизведения и версию кода.

Секреты и токены хранятся только локально или в GitHub Secrets, но не в данных и не в конфигурациях репозитория.
