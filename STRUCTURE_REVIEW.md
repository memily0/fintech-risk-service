# Structure review

## Выполнено

Подготовлен каркас ArcShift 2.0 для данных, исследований, моделей и продукта. Существующие рабочие пути не изменены. Добавлены правила командной разработки, описание происхождения данных, CODEOWNERS и минимальный CI без сети и закрытых данных.

## Архитектурные наблюдения

1. `app/dashboard.py` и будущий `app/dashboard/` временно сосуществуют. Перенос точки входа сейчас нарушил бы существующую команду запуска; его следует делать отдельно с проверкой импорта и деплоя.
2. Текущие CSV уже отслеживаются обычным Git, а полные лицензии, контрольные суммы и происхождение локальных файлов ОФЗ/инфляции не задокументированы. До новых публикаций требуется data review.
3. `requirements.txt` содержит единый набор зависимостей для дашборда, сборки данных и анализа без фиксации версий. Разделение и lock-файл разумны после определения окружений, но не нужны для текущего структурного изменения.
4. Сборщик объединяет загрузку, преобразования и валидацию в одном крупном скрипте. Рефакторинг отложен, чтобы не менять поведение в рамках подготовки структуры.
5. Git LFS/DVC пока не настроены: для этого нужно решение о хранилище, доступах и политике версий.
