# Research

Каталог зарезервирован для отобранных и воспроизводимых материалов ArcShift 2.0. Исследования P1/P2 пока остаются в отдельном репозитории и не переносятся сюда без отдельного решения после ревью.

Эксперимент должен фиксировать гипотезу, данные и их версию, разбиение, метрики, параметры, случайные seed и ссылку на воспроизводимый результат. Проверенный стабильный код модели следует переносить в `models/`, а не использовать исследовательский ноутбук как продуктовую зависимость.
