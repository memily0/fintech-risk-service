# Embedded Report Font

LiberationSans-Regular.ttf is copied unmodified from the installed pdfjs-dist
standard_fonts distribution. Copyright and SIL Open Font License 1.1 are
preserved in LICENSE_LIBERATION. It is bundled for portable Cyrillic PDF
rendering; no system/proprietary Arial file is redistributed or required.
The font is not exposed by the web asset allowlist. PDF documents embed a subset.
