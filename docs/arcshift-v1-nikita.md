## Карта экранов

| Раздел | Действие и результат |
|---|---|
| Обзор России | Смотрю последние условные наблюдения и динамику курса, открываю список предупреждений. Мировой ряд показан как контекст. |
| История рядов | Выбираю показатель и период. Вижу единицу, источник, определение, календарь, публикацию, получение, пропуск и ревизии. |
| Предупреждения | Фильтрую по личному статусу. Системный идентификатор связан со снимком и версией политики. |
| Разбор сигнала | Смотрю тип оценки, задачу, горизонт, версии, время и статус калибровки. Вклады в фикстуре отсутствуют. |
| Личная проверка | Сохраняю статус и заметку. Закрытие и отклонение требуют заметки, переходы записываются со временем UTC. |
| Список наблюдения | Сохраняю ряды в списке своего демо-аккаунта. |
| Отчёты | Фиксирую снимок и проверку, открываю сохранённый отчёт и скачиваю PDF, CSV или JSON. CSV содержит наблюдения. PDF и JSON также содержат личную проверку. |
| Аккаунт | Моделирую регистрацию без приглашения, вход в Демо A/B и выход. Реальная проверка почты и восстановление относятся к I03. |
| Методология | Сопоставляю демонстрационную задачу с ограничениями fitted, OOS и рабочего прогноза. |

Сценарии **Загрузка**, **Пустой набор**, **Ошибка источника**, **Устарело**, **Горизонт не поддерживается**, **Пропуск данных**, **Рынок закрыт**, **Свеча не закрыта** меняются в сайдбаре. Исторический пример содержит условный score 0.35 на некалиброванной шкале. Остальные сценарии возвращают пустой сигнал. Публикация с неизвестным временем отображается отдельно от получения, включая экспорт. Обновление выполняется по кнопке в демо. Календарь закрытия и ожидаемая задержка источника требуют допуска.

## Запуск из чистого checkout

Из корня репозитория, Python 3.14 на проверенной машине.

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r app/requirements-ui.txt
.venv/Scripts/python.exe -m streamlit run app/dashboard.py --server.address 127.0.0.1 --server.port 8767 --server.headless true --client.toolbarMode minimal --browser.gatherUsageStats false
```

В браузере открыть [локальный интерфейс](http://127.0.0.1:8767). Шрифт PDF берётся из системного Arial или DejaVu Sans. Для другой системы можно задать `ARCSHIFT_PDF_FONT` с абсолютным путём к кириллическому TTF.

Для быстрого прохода войти как Демо A, открыть **Предупреждения → Разобрать сигнал → Перейти к личной проверке**. Сохранить вымышленную заметку, открыть **Отчёты**, создать отчёт и скачать его. При переходе в рабочий режим действует блокировка I03/I04 и допуска. Для запуска прежнего экрана можно добавить `-- --legacy` к той же команде. Экран помечен как архивный, fitted-оценка относится к обучающей выборке.

## Контракт, данные и доступ

- [Точка входа](../app/dashboard.py) подключает [интерфейс](../app/analyst_workspace.py). [Клиент](../app/workspace_client.py) отделяет чтение снимка от личного состояния. [Экспорт](../app/workspace_reports.py) использует одну разрешённую копию отчёта. Опубликованный пакет, схемы и общие API-маршруты сохранены в базовой версии.
- Снимок `synthetic-ui-001`, фикстура `v1-handoff.1`, источник `synthetic:arcshift-ui`, определения `synthetic:fx:v1`, `synthetic:equity:v1`, `synthetic:global:v1`, календарь `synthetic-session-calendar-v1`. Времена с явным смещением UTC. Политика `synthetic-warning-v1`, warning ID `synthetic-ui-001:synthetic-warning-v1`.
- Задача `synthetic:future_stress_proxy`, цель `synthetic:stress-proxy:v1`, RU, 30 календарных дней. Версия `synthetic-no-fitted-model` обозначает отсутствие модельного артефакта. Признаки, разбиения, fitted/OOS-метрики и проверка калибровки отсутствуют в демо. Открытие экранов читает локальные фикстуры.
- Разрешения демо заданы на стороне клиента. Все три ряда доступны для показа. Только USD/RUB и условный индекс входят в выгрузки. `export_allowed` используется внутри демо, без ID решения о реальном использовании источника. Допуск display/model use/export/API для реальных источников ожидается отдельно по каждому назначению.
- Личные записи сохраняются в `.cache/arcshift-ui/demo.sqlite3` или по пути `ARCSHIFT_DEMO_DB`. У каждой Streamlit-сессии свои непрозрачные идентификаторы акторов. Смена аккаунта сбрасывает личные виджеты, запросы SQLite включают owner. Вход в тот же демо-аккаунт в пределах одной сессии возвращает сохранённое состояние. Новая браузерная сессия создаёт новые демо-идентификаторы.
- Браузер получает файлы из активной авторизованной демо-сессии, через встроенные ссылки в iframe. ID отчёта сам по себе файл не открывает. Скачанная копия остаётся у получателя. Приватный production endpoint, сессии I03, лимиты, срок хранения и восстановление принадлежат I04. Для хранения используйте только вымышленные заметки. SQLite-схема создаётся при обращении к личному разделу и отделена от старых данных. Для чистого демо можно задать другой путь SQLite.
- Пины Streamlit, Plotly и ReportLab находятся в [requirements-ui.txt](../app/requirements-ui.txt). Playwright и pypdf требуются для тестов. При подключении I04 встроенную выдачу через `st.iframe` заменит защищённый маршрут отчётов.

## Проверки и материалы

```powershell
.venv/Scripts/python.exe -m pip install -r tests/requirements-ui-test.txt
.venv/Scripts/python.exe -m playwright install chromium
.venv/Scripts/python.exe -m unittest discover -s tests -p 'test_workspace_*.py' -v
.venv/Scripts/python.exe -m pip install -r product_build/arcshift_v1/tools/requirements.test.txt tzdata
.venv/Scripts/python.exe -X utf8 -m unittest discover -s product_build/arcshift_v1/research/tools/release -p test_v1_data_contract.py -v
```

Playwright использует запущенный локальный экземпляр из команды выше. Для другого порта задать `ARCSHIFT_UI_URL`. Все снимки экрана и пример отчёта используют вымышленные данные. Тесты контракта данных прошли 27/27. У исходного `check_bundle.py` на Windows два сбоя связаны с системной кодировкой и разделителями путей. Отдельно прошли 7 остальных проверок в UTF-8 и сверка 59 путей, размеров и SHA-256 замороженного пакета. Сверка учитывает LF в Git и CRLF в checkout.

Прогон интерфейса прошёл 7/7, из них 4 проверки клиента и 3 сценария Playwright в Chromium. Первые браузерные прогоны выявили разрыв заголовка при 200% на 375 px и затруднение с раскрывающимся списком наблюдения. В итоговом интерфейсе детали складываются в одну колонку на узких экранах, ряды выбираются флажками. Архивный вход проверен отдельным smoke через Streamlit AppTest.
